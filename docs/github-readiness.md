# GitHub readiness record

This repository is intentionally publishable before empirical results exist.

## Included

- Clear local-first execution policy
- Notebook-only runtime boundary
- Security and contribution guidance
- Issue and pull-request templates
- Explicit generated-artifact and evidence rules
- README architecture and research-status sections

## Not included yet

- Empirical rates or Wilson intervals
- W&B links or artifacts
- Deployment URLs
- Raw traces or provider responses

Those items require runtime evidence and separate approval. No CI workflow is included because this project must not schedule CPU tests automatically.
